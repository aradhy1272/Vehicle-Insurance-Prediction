# 🚗 Vehicle Insurance Prediction

A Machine Learning project that predicts whether a customer is interested in purchasing vehicle insurance based on demographic and vehicle-related information.

## 📌 Project Overview

Insurance companies often need to identify customers who are likely to buy vehicle insurance. This project uses Machine Learning algorithms to predict customer interest, helping businesses improve marketing strategies and customer targeting.

---

## 🎯 Objectives

- Predict whether a customer will purchase vehicle insurance.
- Perform data preprocessing and exploratory data analysis (EDA).
- Train and evaluate Machine Learning models.
- Compare model performance using evaluation metrics.

## 📊 Dataset Features

The dataset contains customer information such as:

- Gender
- Age
- Driving License
- Region Code
- Previously Insured
- Vehicle Age
- Vehicle Damage
- Annual Premium
- Policy Sales Channel
- Vintage
- Response (Target Variable)

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/aradhy1272/Vehicle-Insurance-Prediction.git
```

Move into the project directory:

```bash
cd Vehicle-Insurance-Prediction
```

Install the required packages:

